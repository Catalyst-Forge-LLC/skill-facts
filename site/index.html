The boundary

ToolFacts labels an executable instrument. SkillFacts labels instructions an agent follows. AgentFacts labels an actor configuration.

Skills are the plain-English supply chain: installable playbooks that can tell an agent to run scripts, fetch URLs, or move data. Nothing today puts a comparable label on that surface.
